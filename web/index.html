Riparto delle spese dai report Siemens

Questa pagina trasforma il file FC_report, esportato dal sistema Siemens, e il file dei dati statici nel file Riparto in formato Excel, con il riparto delle spese di riscaldamento e dell'acqua tra gli appartamenti.

  1. Scegliere o trascinare qui sotto il file FC_report (il file .xls esportato dal sistema Siemens) e il file dei dati statici (il file .xlsx compilato per l'esercizio). I due file si possono scegliere in qualsiasi ordine.
  2. Attendere la fine della conversione.
  3. Scaricare il file Riparto e leggere le eventuali segnalazioni sotto «Attenzione».

Il file dei dati statici si compila a partire da static_data_template.xlsx, che si scarica anche dalla pagina dell'ultima versione.

Caricamento del programma di conversione in corso. Alla prima visita può richiedere qualche istante.

    Riservatezza dei dati

    I file scelti vengono elaborati soltanto in questo browser, sul computer in uso, e non vengono inviati a nessun server. La pagina non usa strumenti di analisi né script di terze parti.

    Il programma per Windows e per Linux resta disponibile nella pagina dell'ultima versione.
